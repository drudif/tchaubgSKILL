# tchaubgSKILL

Skill do Claude Code que remove o fundo de fotos e devolve PNG com transparência,
em lote e 100% local. Versão linha de comando do TCHAU.BG.

## Stack
Python · rembg + onnxruntime · Pillow

## Estrutura
- `SKILL.md` — a skill
- `scripts/` — o executável

## Comandos
- `pip install -r requirements.txt`

## Armadilhas
- Repo **público**. Nada de caminho pessoal, credencial ou foto real nos exemplos.
- Versões testadas estão pinadas com data no `requirements.txt` — mantenha o comentário atualizado ao subir versão.
- `../recortar-retratos` é a versão web da mesma ideia, repo separado. Correção aqui não vai para lá.

Histórico de decisões: `docs/DIARIO.md`
